# 2 · Network construction (four TF–target layers)
- **`RFN_expression/`** — RF-inferred regulatory network from expression (`Fig_Coexpression.v3.R`; formerly labeled "CEN"/co-expression, built with random-forest regression per Zhou et al. 2020).
- **`GAN_trans_eQTL/`** — trans-eQTL gene-association network (`Set_Input_to_Fig_transeQTL.R`, `Fig_transeQTL.v3.R`).
- **`GRN_PDI/`** — protein–DNA-interaction network (`Fig_PDI.v4.R`, `Fig_PDI_newDAP.R`).
- **`eGRN_cis_eQTL/`** — cis-eQTL-supported PDI network (`Fig_ciseQTL.R`).
